# FULLCOURT DATA | B.PREMIER / B.ONE

B.LEAGUEファン向けの**独立した非公式スタッツサイト**です。ユーザーから提示されたBリーグファンサイトの「ホーム → 選手・クラブ → ランキング → 個別の詳細」という情報構造を参考に、オリジナルのデザイン・コードで作成しています。

- 対象：**2026–27レギュラーシーズン**、B.PREMIER **26クラブ** / B.ONE **25クラブ**
- 動作環境：PC・スマートフォン／HTML・CSS・JavaScriptのみ（ビルド不要）
- データ：B.LEAGUE公開済み試合データを非公式ラッパー `sportsdataverse-py` で収集し、終了試合の記録を累積集計
- 更新：GitHub Actionsで通常2時間ごと、夕方〜深夜は追加で1時間ごとの更新チェックを設定

## ホーム画面・機能

| 画面 | 内容 |
| --- | --- |
| ホーム | 直近の終了試合、得点／REB／ASTリーダー、主要指標の注目値、クラブ一覧、地区別勝敗一覧 |
| 選手 | 名前／英語名／背番号で検索、所属クラブと出場試合数で絞込み、全主要指標の列ソートとCSV |
| クラブ | 全51クラブの切替式一覧、クラブカード、全主要指標の一覧・検索・CSV |
| ランキング | **選手／クラブを切り替えて**対象の基本・シュート・アドバンスド指標を選択・比較 |
| 試合 | 終了済み全試合の結果。クリックすると**試合のチーム指標と選手別BOX SCORE** |
| 比較 | 同一リーグの2選手／2クラブで主要指標を左右比較 |
| 選手プロフィール | 主要成績、全指標、直近12試合の得点バー、試合別ログと各試合BOX SCORE |
| クラブプロフィール | 勝敗、主要成績、全指標、所属選手一覧、試合別ログ |

### 指標

- 選手：G / GS / MIN / PTS / REB / ORB / DRB / AST / STL / BLK / TOV / FG / 2PT / 3PT / FT（成功・試投・成功率）、EFF、+/−、PF / FD / 被ブロック、AST/TO、TS%、eFG%、TOV%、USG%、推定ORtg・DRtg・NetRtg、参考POSSなど。
- チーム：上記のチーム集計、勝利数・敗戦数・勝率、得点・失点・得失点差、ORB% / DRB%、FT Rate、推定PACE、推定ORtg・DRtg・NetRtg、セカンドチャンスポイント、ペイント内得点、速攻得点、ターンオーバーからの得点など。
- 表示：試合平均／シーズン合計。算出できない数値は「—」と表示（勝率・成功率などは期間集計値から再計算）。

## 現在のデータ状態（重要）

同梱の `site/data.js` には**2026年11月16〜17日時点の51クラブの保存済み勝敗スナップショットだけ**を収録しています。実際の全試合のボックススコアと**全選手の成績は未取得**です。架空の選手・試合データは一切入れていません。

公開後にGitHub Actionsの**初回全試合同期が成功**すると選手成績、試合結果、選手名簿が自動表示されます。選手名簿は公開済みの試合に記録された選手を集計する方式です。未出場・未登録の選手は対象に含まれない場合があります。**初回同期の実データ取得成功はこの制作環境では未検証**です。

このサイトには試合前の日程、AI独自採点、勝敗予測、ニュース、ログイン／掲示板はありません（不確実な情報を捏造しないため実装していません）。

## 公開手順（GitHub Pages）

1. ZIPを展開し、`site/` `scripts/` `.github/` `requirements.txt` `README.md` などを**GitHubリポジトリ直下**にアップロードします（フォルダを一階層余分にしない）。
2. GitHubリポジトリの `Settings → Pages → Build and deployment → Source` で **GitHub Actions** を選びます。
3. `Settings → Actions → General → Workflow permissions` で **Read and write permissions** を有効にします。許可できない組織・リポジトリでは自動保存できません。
4. `Actions → Update B.LEAGUE data and publish → Run workflow` を実行します。初回の全シーズン照合・試合データ取得を試み、成功した終了試合を `site/data.js` に出力します。
5. `Actions` に表示されたGitHub Pagesの公開URLを開いてください。以後、スケジュールに従ってデータ取得を実行します。

**注意：公開だけでは試合データが集まるわけではありません。** 同期ジョブが実行され、取得に成功して初めて成績が表示されます。また、試合終了直後に即更新されるわけではなく、公開データ提供とジョブ実行の間に時間差があります。

### ローカルで試す

`site/index.html` をブラウザで開くと保存済み順位を確認できます。ローカルでデータ取得する場合：

```bash
python -m pip install --pre -r requirements.txt
python scripts/update_stats.py --backfill
python scripts/update_stats.py
```

Webサーバーで表示する場合は `python -m http.server 8000 --directory site` で `http://localhost:8000/` を開いてください。

## 集計の定義

- FG% = (2PM + 3PM) ÷ (2PA + 3PA) × 100
- eFG% = (FGM + 0.5 × 3PM) ÷ FGA × 100
- TS% = PTS ÷ {2 × (FGA + 0.44 × FTA)} × 100
- AST/TO = AST ÷ TO（分母ゼロは「—」）
- 推定ポゼッション = FGA − ORB + TOV + 0.44 × FTA
- 推定ORtg = PTS ÷ 推定ポゼッション × 100
- 推定DRtg = 対戦相手PTS ÷ 対戦相手の推定ポゼッション × 100
- 推定PACE = 両チームのポゼッション平均を40分換算
- ORB% = ORB ÷ (ORB + 相手DRB) × 100、DRB% = DRB ÷ (DRB + 相手ORB) × 100
- 個人USG%など試合別の参考レーティングは出場時間を加重して平均
- **2nd CHはゲーム集計からチーム別に表示**します。個人への得点配分は未確認のため個人成績として表示しません。

## 検証済み／未検証

**検証済み：** 既存Python集計ロジックの単体テスト（4件）、ブラウザでの26／25クラブ切替、クラブ詳細、検索画面・ランキング切替、PC／スマホ表示、**テスト用の架空の試合データのみを用いた**選手・クラブプロフィール／試合BOX／比較機能。

**未検証：** 公式の本番全試合データ取得、GitHub Pages環境での定期更新・長期運用。実データの取得元ライブラリ・ウェブサイトの仕様変更、アクセス制限、提供の遅延で停止する場合があります。

公式掲載成績と比べて、推定レーティングおよび公式順位（同勝率の直接対決優先等）は一致しない場合があります。データの利用・転載条件を確認したうえで公開してください。

## ファイル構成

- `site/`：ブラウザに表示するフロントエンド
- `scripts/update_stats.py`：終了試合をチェック、個人・クラブ集計、`site/data.js`出力
- `scripts/seed_snapshot.py`：順位の初期スナップショット生成
- `tests/test_sync.py`：集計処理のテスト
- `.github/workflows/update.yml`：定期更新とGitHub Pages配信
- `cache/games_2026-27.json`：同期後に生成する過去試合キャッシュ（初期ZIPにはありません）
